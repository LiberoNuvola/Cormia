# Licensing decision — OPEN / publication blocker

No code or documentation license is selected by this initial scaffold.

Options to evaluate before public release:

- **Code:** Apache-2.0 is a candidate for implementation code, subject to owner/contributor approval and dependency compatibility review.
- **Documentation/specification:** CC BY 4.0 is a candidate for prose and diagrams, subject to owner/contributor approval.
- **Schemas/test vectors:** may follow the code license or a separately declared specification license; decide before external contributions.

Do not add a license file or claim that this repository is open-source until the rightsholder approves the choice and all imported code is audited for compatibility. Public visibility alone does not grant reuse rights.
