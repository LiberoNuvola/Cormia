# ADR-0005: IMMORTAL Hive as the working product identity

- **Status:** Proposed working name; not trademark-cleared
- **Date:** 2026-11-02

## Context

IMMORTAL-AEP is a precise engineering/protocol label but not an approachable product name for an installable, local-first AI network.

## Decision proposal

Use the following naming layers while preserving the historical IMMORTAL identity:

- **IMMORTAL** — project/ecosystem umbrella.
- **IMMORTAL Hive** — user-facing application and reciprocal AI mesh (working name).
- **IMMORTAL Protocol / AEP** — normative rules, identity/capabilities, task lifecycle, reciprocity accounting, verification, dispute, settlement and governance.
- **IMMORTAL Runtime** — software installed on each device; a device running it is a Hive Node/Worker.
- **Compute Reciprocity Credits (CRC)** — provisional name for non-transferable internal access accounting.

Proposed tagline: **Your AI locally. Shared intelligence when you contribute.**

## Rationale

“Hive” communicates many independent devices contributing capacity to a shared network. It is more approachable than “AEP” while avoiding the suggestion that the user must buy a crypto token.

## Constraints

- This is not a legal trademark clearance.
- A preliminary exact-name web search did not establish a definitive collision, but does not establish availability.
- Keep the repository slug `immortal-autonomous-execution-protocol` until the owner confirms the final name and a remote repository exists.
- Do not rename existing IMMORTAL Protocol or local-agent repositories as part of this ADR.
